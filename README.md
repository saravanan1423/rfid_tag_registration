<h1>RFID REGISTRATION TAGS</h1>

This project is about registring the RFID tag product according to it names.Since the tag is read from the UHF Sensor it provide the EPC code of it in which it contain an unique value for different groups.We can able to monitor which group are registered in it.The UHF reader is connected via the TCP/IP and it can be run through the local host since it is combined with the hardware.<br>

These are simple webpage which consist of three pages login page, registration page and the registered table page.<br>

The programming language used for the backend development is <b>python</b><br>

The programming language used for the frontend development are<br>
<b>1)HTML</b><br>
<b>2)CSS</b><br>
<b>3)JavaScript</b><br>

The database used here to store the datas are <b>MySQL</b><br>

The web framework used here is <b>FLASK</b>.
